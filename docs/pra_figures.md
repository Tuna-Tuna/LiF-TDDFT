# PRA figures and EPS verification

`scripts/reproduce_pra_figures.py` reproduces figures 2–6 from the author's
final plotting tables and arrays. It does not run RT-TDDFT, refit data, or
recalculate capture, detachment, or final fractions. Figure 1 comes from a
separate native figure and is not regenerated by this script.

## Installation and inputs

Use Python 3.10 or newer and install the plotting extra:

```bash
python -m pip install -e ".[figures]"
```

Install Times New Roman locally to reproduce the manuscript typography.
The script fails if that family is missing. An explicit alternative such as
`--font-family "DejaVu Serif"` changes typography and requires a new layout
review. No proprietary font files are distributed with this repository.

Numerical plotting inputs are author-supplied and are not tracked in this
code-only repository. Point `--data-dir` to their `source_data` directory:

| Directory | Required files |
| --- | --- |
| `figure2/a_potential` | `panel_a_embedded.csv`, `panel_a_li25.csv`, `panel_a_slab.csv` |
| `figure2/b_density` | `profile_embedded.csv`, `profile_li25.csv`, `profile_slab.csv` |
| `figure2/c_radial` | `radial_differences.csv` |
| `figure2/d_integrated` | `panel_d.csv` |
| `figure3` | `probability.csv`, `point_charge_distance.csv` |
| `figure4` | `merged.csv` |
| `figure5` | `radial_current_manifest.json`, `panel_a_radial_field.npz`, `panel_b_radial_field.npz`, `panel_c_signed_flux_v030.csv`, `selected_phases.csv`, `panel_d_balance.csv` |
| `figure6` | `Fig6a_force.csv`, `Fig6b_trajectories.csv`, `Fig6c_capture.csv`, `Fig6d_force_sensitivity.csv`, `Fig6d_no_detachment.csv`, `Fig6d_experiment.csv` |

Column names and units are read explicitly by the plotting functions. Missing
files or columns cause an error. Display interpolation is limited to current
arrows and flux markers. The final numerical plotting columns are authoritative;
obsolete provenance flags in older CSV/README annotations are not interpreted
as additional physical models.

## Generate and review

Install Ghostscript for EPS conversion and ensure `gs` (Unix) or `gswin64c`
(Windows) is on `PATH`, or provide its full executable path:

```bash
python scripts/reproduce_pra_figures.py --data-dir /path/to/source_data --verify-eps
python scripts/reproduce_pra_figures.py --data-dir /path/to/source_data --figures 5 6 --verify-eps --ghostscript /path/to/gswin64c.exe
```

The default output directory is `results/pra_figures`, which Git ignores.
`--output` selects another directory. Each figure has EPS, PDF, PNG, and TIFF
versions. PNG/TIFF and raster portions of EPS/PDF are exported at 600 dpi;
vector lines and text remain resolution independent.

`figure_audit.json` records source hashes, dimensions, text sizes, axis positions,
numeric checks, and EPS glyph checks. With `--verify-eps`, `eps_review/` contains
the PDF converted **from the EPS**, a rendering of that PDF, and conversion logs.
Inspect these rendered files alongside the direct PNGs; a successful converter
exit status alone does not prove that text or labels survived.

The script preserves the final manuscript layout: no extra hemisphere annotation
in figure 2(c); no contours in figure 5(a,b); no explanatory titles above
figure 5(c,d); aligned figure 5 columns; and figure 5(c,d) and all figure 6
frames use figure 4's width/height ratio (approximately 1.1382). Figure 5(a,b)
retain their wider geometry. The figure 6 legends remain inside panels (b,d).
The `Experiment [21]` label follows this manuscript's numbering and must be
reviewed if its reference list changes.

## Why checked EPS export is needed

A font-export combination of Matplotlib 3.11.1 and fontTools 4.63.0 was observed
to emit Type 42 EPS with names such as `/uni00000015 glyphshow` while the
embedded font defined `/two`. Ghostscript completed conversion but silently
omitted the unresolved text. This diagnosis applies to the inspected files;
it is not a claim that every Type 42 exporter fails.

`lif_tddft.eps_export.save_eps` exports Type 3 vector glyph outlines, verifies
that every named glyph exists in the active embedded font, and only then
replaces the requested output file. This does not rasterize the entire figure.
Direct PDF export retains its existing font settings. Type 3 text need not be
searchable or copyable, so judge its visual appearance from the rendering.

Existing EPS files can be checked independently:

```bash
python scripts/check_eps_fonts.py /path/to/figure.eps
python scripts/check_eps_fonts.py /path/to/eps_directory --render-dir results/eps_review
```

The checker understands Matplotlib's embedded-font/glyphshow convention. It is
not a general PostScript validator or automatic visual approval. It reports
undefined glyphs rather than guessing how to repair arbitrary third-party EPS.

## Tests

```bash
python -m unittest discover -s tests -v
```

The EPS tests cover the original undefined-glyph failure, per-font glyph
resolution, vector-outline export, and visible regular/bold/italic text after
EPS → PDF → PNG conversion. The integration test uses Ghostscript from `PATH`
or the `GHOSTSCRIPT` environment variable; it is skipped if none is available.
