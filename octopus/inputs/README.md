# Tracked Octopus inputs

These eight files are representative `v=0.30` production inputs, one for each
height in the manuscript grid. Regenerate them with
`python octopus/generate_reference_inputs.py`.

The complete 96-run paired campaign is generated from
`config/campaign_revision.yaml` by `octopus/generate_inp_files.py`. The tracked
examples are not a substitute for the independent per-velocity manifests.
