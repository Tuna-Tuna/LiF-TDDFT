# F-/LiF fragment benchmark

Production benchmark geometries comprise isolated F-, isolated LiF, and three
F-...LiF separations (far negative control, orthogonalization onset, and short
range).  Compare LB94/PW92 with a verified self-interaction-corrected branch.
Required outputs are HOMO level, electron affinity, density tail, short-range
force, local population, occupied overlap, and orthogonalization cost.

This benchmark probes electronic-structure robustness.  It is not validation
of the Demkov capture probability.
